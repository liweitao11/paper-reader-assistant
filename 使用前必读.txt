paper-reader-assistant · 使用前必读
═══════════════════════════════════════════════════════════

【这是什么】
一款本地运行的论文阅读工具：
  Zotero 文献 → 自己（或AI ）精读 → Obsidian 结构化笔记
支持云端 AI（OpenAI / DeepSeek / 豆包 / 自定义）和本地 AI（Ollama）。


【环境要求】
  1. Windows 10/11
  2. Python 3.10 或更高版本（安装时勾选 Add Python to PATH）
  3. 可选：Zotero（读取文献库）、Obsidian（存放笔记）（其实有没有都行）
  4. 可选：Ollama（本地 AI 分析）（too）


【如何启动】（任选一种）
  方式一：双击 PaperReader.cmd
  方式二：双击 启动.pyw（无黑窗口）
  方式三：命令行
          python 启动.pyw

启动成功后会自动打开浏览器：http://127.0.0.1:8774


【第一次使用步骤】
  1. 打开页面后，先点击右下角 AI 球
  2. 选择 AI 方式：
     - 云端：选 OpenAI / DeepSeek / 豆包，填 API Key
     - 本地：选 Ollama，先选择模型目录，再下载/选择模型
  3. 点击“选择 Obsidian 目录”，指定笔记保存位置
  4. 从右侧 Zotero 栏选一篇论文，或点击“读取本地文档”
  5. 填写研究方向和标签
  6. 点击 AI 分析，等待 JSON 自动填入
  7. 人工核对后点击“生成 Obsidian 笔记”
  8. 处理下一篇前点击“一键清空”


【Zotero 说明】
  - 程序只读访问 Zotero 数据库，不会修改、不会写回
  - 默认读取：C:\Users\你的用户名\Zotero\zotero.sqlite
  - 如果 Zotero 数据目录是自定义位置，程序会自动从
    Zotero 的 prefs.js 中查找，无需手动配置
  - 找不到数据库时仍可使用“读取本地文档”功能


【AI 与隐私】
  - 云端模式：论文正文会发送给所选 AI 服务商
  - 本地模式（Ollama）：论文不出本机
  - API Key 默认不保存；勾选保存时使用 Windows 用户级加密
  - 涉密论文建议使用本地模型


【常见问题】
  Q1: 双击没反应？
     A: 确认 Python 已安装且加入 PATH；或右键 PaperReader.cmd 用管理员运行。

  Q2: 页面打不开？
     A: 查看启动窗口是否报错；确认 8774 端口未被占用。

  Q3: Zotero 列表为空？
     A: 确认 Zotero 安装并运行过，且数据库中确实有主文献。

  Q4: 本地模型下载失败？
     A: 检查磁盘空间、网络，确认已选择模型目录。

  Q5: AI 输出 JSON 解析失败？
     A: 换更强模型（Qwen2.5 14B 或云端模型），或减少论文长度。

  Q6: 扫描版 PDF 没正文？
     A: 需要先用 OCR 生成文字层。


【关闭程序】
  关闭浏览器页面并确认离开，或点击页面右上角红色 ×。
  后台 Python 和它启动的 Ollama 会一起停止。
  模型文件不会被删除，下次启动自动重新加载。

  templates/index.html  前端页面
